HTML - hyperText Markup Language

Linguagem de Marcação de Hipertexto

De forma simples, o HTML é a linguagem usada para montar a estrutura de uma página da internet. Ele diz ao navegador onde fica o título, os textos, as imagens, os botões, os links e outros elementos do site.

CSS - Cascading Style Sheets

Folhas de Estilo em Cascata

É a linguagem usada para definir a aparência de uma página da web. Enquanto o HTML cria a estrutura, o CSS deixa a página bonita e organizada.
